#### Automation and data pipelines

- **[Jeff-winter](https://github.com/ahmed-tiffrent/Jeff-winter)** (client project): a Node.js script that pulls blog posts from a Squarespace site, cleans them into structured records and loads them into an Algolia index. GitHub Actions runs it every week, so nobody has to update the index by hand.
- **Shopify stock tool** (internship, code private): a Cloudflare tool that sets exact stock levels in Shopify for recycled sequin waste, built with AI-assisted coding.

#### Data analysis and machine learning (university projects at ESI-SBA, built with [Aymen Allag](https://github.com/allagaymen))

- **[M-taheuristiques-base-de-jeu](https://github.com/allagaymen/M-taheuristiques-base-de-jeu)**: cleans and encodes a Facebook profiles dataset, selects features, tunes a Random Forest with the Tiki-Taka metaheuristic to detect fake profiles, and reports accuracy, precision, recall, F1 and ROC-AUC with a feature importance chart.
- **[Cardio_disease_with_FIS](https://github.com/allagaymen/Cardio_disease_with_FIS)**: a Flask app that scores cardiovascular risk from 11 health inputs using 28 fuzzy rules, and sorts the result into low, medium or high bands with set thresholds.
