### Hi, I'm Ahmed Amine Tiffrent

Computer Science engineer (ESI-SBA, Algeria) with an MSc in User Experience Design (University of Brighton, Distinction), based in Brighton, UK.

I look at how a process works today, find the manual steps, build tools that remove them and measure whether the change worked.

#### Automation and data pipelines

- **[Jeff-winter](https://github.com/ahmed-tiffrent/Jeff-winter)** (client project): a Node.js script that pulls blog posts from a Squarespace site, cleans them into structured records and loads them into an Algolia index. GitHub Actions runs it every week, so nobody has to update the index by hand.
- **[jeff-newsletter-tool](https://github.com/ahmed-tiffrent/jeff-newsletter-tool)** (client project, [live](https://jeff-newsletter-tool.netlify.app/)): a web tool that collects Industry 4.0 event news from Google News, lets the client shortlist stories and add commentary, and exports the shortlist to Excel.
- **[tssc-shopify](https://github.com/ahmed-tiffrent/tssc-shopify)** (internship): a Cloudflare Worker that adds recycled sequin waste to stock after each order and syncs the catalogue to Etsy, plus scripts that audit the Google Merchant feed and reconcile products, pricing and stock.
- **[job-radar](https://github.com/ahmed-tiffrent/job-radar)**: a Next.js and Supabase tracker that pulls live vacancies from the Adzuna API, scores fit with schema-checked AI output and tracks each application.
- **[feedback-aggregator](https://github.com/ahmed-tiffrent/feedback-aggregator)** ([live](https://feedback-aggregator.a-tiffrent1-45c.workers.dev/)): a Cloudflare Worker that labels product feedback by sentiment, theme and urgency, scores its priority and shows totals on a dashboard.
- **[content-tool](https://github.com/ahmed-tiffrent/content-tool)**: Python scripts that check and publish scheduled posts to LinkedIn, X and Instagram through their APIs.

#### Final year project (MSc and Engineer in Computer Science, ESI-SBA, 2025)

- **[fish-freshness-estimator](https://github.com/ahmed-tiffrent/fish-freshness-estimator)**: an EfficientNetB3 model that rates fish freshness from a photo of the eye, with 81.06% test accuracy on 3 balanced classes, served in a Streamlit app with Grad-CAM heatmaps.

#### Dashboards and data analysis

- **[sprint-dashboard](https://github.com/ahmed-tiffrent/sprint-dashboard)** (MSc, University of Brighton): a React and Recharts dashboard built from a Scrum spreadsheet, with progress figures, a burndown chart of ideal against actual effort, and a task board.
- **[spark-bike-share-graph](https://github.com/ahmed-tiffrent/spark-bike-share-graph)** (ESI-SBA lab): models bike-share trips as a graph with PySpark and GraphFrames to find busy routes, unreached stations and the busiest destinations.

#### Data analysis and machine learning (university projects at ESI-SBA, built with [Aymen Allag](https://github.com/allagaymen))

- **[M-taheuristiques-base-de-jeu](https://github.com/allagaymen/M-taheuristiques-base-de-jeu)**: cleans and encodes a Facebook profiles dataset, selects features, tunes a Random Forest with the Tiki-Taka metaheuristic to detect fake profiles, and reports accuracy, precision, recall, F1 and ROC-AUC with a feature importance chart.
- **[Cardio_disease_with_FIS](https://github.com/allagaymen/Cardio_disease_with_FIS)**: a Flask app that scores cardiovascular risk from 11 health inputs using 28 fuzzy rules, and sorts the result into low, medium or high bands with set thresholds.
